## Method

Requirements and other sections are pattern-matched evidence excerpts for analyst review, not a substitute for the controlling solicitation. The public SAM.gov opportunities API exposes the latest active version; this tracker therefore records bounded extracted-evidence snapshots and does not declare which file is controlling.
